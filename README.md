# CISC 4900 - Final project - Online ebook library 

The project is to develop a website that gives the user an easy and accessible
way to read ebooks online.

It will be a platform that will have a verity of different genres of books, modern features,
and something anyone can use.

<h2> Features of website </h2>

* **Show casing each book**

  * Picture of the book cover
  * Small description of book
  * Movie trailer to book if applicable
    
 
* **Reading the book**

  * Being able to open a pdf version of the book
  * Have the ability to save your progress
  * Vote on whether you liked or disliked the book
 
* **Different tabs**

  * A home tab that will bring you back home to show you the featured books
  * A Library tab that will show you all the books available
  * A Mybooks tab that will show you all the book you have read
  * A Categories tab that will show you the different genres

* **Resources**

  * Coding in Java and HTML/CSS
  * PDF reader
 
## The reason behind this project

  * Books are the foundation of building and strengthening our minds, gaining knowledge,
  and sharing stories whether fiction or nonfiction. In a world where are constantly
  moving fast and multitasking, the art of books remains vital for humans.
  The purest form of individual expression.
